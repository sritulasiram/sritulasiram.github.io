# Security Policy

This repository is the source of a static personal portfolio ([sritulasiram.my](https://sritulasiram.my)). It has no server, accounts, forms or user data.

## Reporting a vulnerability

Please report privately rather than in a public issue:

- Use GitHub's **Report a vulnerability** option under the repository's Security tab, or
- Contact Sri Tulasi Ram through [sritulasiram.my](https://sritulasiram.my).

Include the affected URL or file, steps to reproduce and the impact you expect. You will get a response as soon as possible; this is a personal project, so there is no formal SLA.

## Scope

In scope: the published site, its dependencies and the deploy workflow. Out of scope: automated scanner output without a demonstrated impact, and missing headers that the hosting platform (GitHub Pages) does not allow to be set.

More detail on the current posture and known gaps is in [docs/security.md](docs/security.md).
